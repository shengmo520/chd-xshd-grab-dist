# 学术活动抢票（下载页）

**下载**：右上角 Releases → 最新版本 → `xshd-grab-x.y.z.exe`，双击即可，不需要装 Python。
本仓库只放程序与更新清单，不含源码。

## 第一次用

1. 双击 exe，浏览器会自动打开 `http://127.0.0.1:8765`；
2. 「账号」里填自己学号 + 学校统一认证密码，点登录（密码不保存，只存令牌）；
3. 左栏勾选要抢的场次，点「开始抢票」。到点前 45 秒会自动发起，抢不到会转成盯退票。

## 自动更新

程序启动时会读本仓库的 `version.json`（走 jsDelivr CDN）。有新版本时页面上会出现
「发现新版 vX.Y.Z，点这里更新」，点一下自动下载、替换、重启，实测 2 秒完成，不用重新下载。

## 注意

- 单文件 exe 容易被杀软误报（PyInstaller 特征），被拦时选「允许运行」；
- 不要放在 `C:\Program Files`，那里没写权限，配置和自动更新都会失败；
- 群里「腾讯文档收集表」是另一条链路：需要在软件里点「打开登录窗口」登一次腾讯文档，
  之后群里复制链接就会自动填表提交。
