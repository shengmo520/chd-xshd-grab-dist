# 学术活动抢票 · 下载页

## 下载

**点这里下载（国内加速，8.7MB）**：
https://gh-proxy.com/https://github.com/shengmo520/chd-xshd-grab-dist/releases/download/v1.1.0/xshd-grab-1.1.0.exe

备用（GitHub 官方页，国内可能很慢）：右上角 Releases → `xshd-grab-1.1.0.exe`

下载后双击即可，不用装 Python，不用注册任何账号。本仓库只放程序和更新清单，不含源码。

## 第一次用

1. 双击 exe，浏览器自动打开 `http://127.0.0.1:8765`；
2. 「账号」里填自己学号 + 学校统一认证密码，点登录（密码不保存，只存令牌）；
3. 左栏勾选要抢的场次，点「开始抢票」；到点前 45 秒自动发起，抢不到自动转盯退票；
4. 群里的腾讯文档收集表：先在软件里点「打开登录窗口」登一次腾讯文档，之后群里复制链接就会自动填表提交。

## 自动更新（不用自己管）

程序启动会读本仓库的 `version.json`（走 jsDelivr CDN）。有新版本时页面上会出现
「发现新版 vX.Y.Z，点这里更新」，点一下自动下载（走 gh-proxy 镜像，约 30 秒）、替换、重启。
下载失败会自动换下一个镜像，最多三个。

## 注意

- 单文件 exe 容易被杀软误报（PyInstaller 特征），被拦时选「允许运行」；
- 不要放在 `C:\Program Files`，那里没写权限，配置和自动更新都会失败；
- 更新过程中别手动挪动 exe。
